# House Prices Prediction 🏠

A beginner machine learning project that predicts house sale prices using Python and the Kaggle House Prices: Advanced Regression Techniques dataset.

## 📌 Project Overview

The goal of this project is to explore a real-world dataset, perform data preprocessing, and build a machine learning model to predict house prices.

Through this project, I practiced data analysis, feature engineering, and model evaluation.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook

## ⚙️ Workflow

1. Explored the dataset and investigated missing values.
2. Handled missing data.
3. Encoded categorical features.
4. Prepared training and test features.
5. Trained and evaluated a Random Forest regression model.
6. Generated house price predictions for the Kaggle competition.

## 📂 Project Files

| File | Description |
|---|---|
| `House_Price_Prediction_Model.ipynb` | Jupyter Notebook containing the analysis, preprocessing, and model experiments |
| `submission.csv` | Predicted house prices submitted to Kaggle |
| `data_description.txt` | Descriptions of the dataset's features |

The original competition datasets are not included in this repository.

## 📊 Results

- **Kaggle Public Score:** 0.14418
- **Evaluation Metric:** Root Mean Squared Logarithmic Error (RMSLE)

A lower RMSLE indicates better prediction performance.
